# Momedamin — Artist Site

## Setup
1. Replace `yourpaypalname` in `index.html` (inside the `<script>` tag) with your real PayPal.me username.
2. Create an `audio/` folder in this repo and add your real mp3 files.
3. Edit the `TRACKS` array in `index.html` to match your song titles, prices, and filenames.
4. Swap the `#` links in the footer for your real Instagram / YouTube / SoundCloud.

## Publish with GitHub Pages
1. Push these files to your repo (main branch).
2. Go to Settings → Pages.
3. Under "Source," select the `main` branch and root folder, then Save.
4. Your site goes live at `https://yourusername.github.io/your-repo-name`.

## Note on payments
PayPal.me doesn't auto-send files after purchase — you'll need to manually deliver the download once someone pays. For automatic delivery, consider Payhip or Ko-fi Shop layered on top of PayPal.
